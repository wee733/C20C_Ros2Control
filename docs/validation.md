本地 Jazzy 编译和完整检查通过：**56 tests, 0 errors, 0 failures, 0 skipped**。新增伪终端断言覆盖启动类型发现且无回显、四类接受指令的回显、拒绝指令无回显、后来连接的订阅者获得最后一次接受的输入。没有为本次验证向实机发送运动命令。

已启动单个 C20D 驱动并重启现有 `airborne-foxglove.service`，保留相机 10 Hz 限速。通过本机 WebSocket `ws://127.0.0.1:8765` 连接实际 bridge，确认 `clientPublish` 能力开启，四个回显频道均广播匹配的 ROS 消息类型与非空完整 schema（分别 1410、1344、1247、1344 字节）。测试在没有任何控制话题发布者的情况下完成，不依赖占位消息。

`colcon build --packages-up-to c20d_driver --symlink-install` 成功。完整 ament/colcon 检查中发现并修复 Python import 排序问题，重跑对应 flake8 检查后，`colcon test-result --verbose` 为 **46 tests, 0 errors, 0 failures, 0 skipped**。这是当前 colcon 汇总报告计数，包含 lint 条目，不是 46 个硬件场景。

ROS/伪终端集成测试覆盖：

- 四种控制话题及其固定模式/操作类型，双轴同帧更新，旧统一控制话题不再有订阅者。
- 相对角、姿态角、真实/比例角速度的正负目标编码；模拟实机反号反馈，核对归一后的目标/反馈对应。

- 比例速度要求新鲜 FOV/倍率、相机信息失效后停止；原有 CRC、回中触发、服务回应、载机过期、断线不重放检查继续通过。

### 原始角速度方向核对

在旧版节点下发送线协议 +2°/s 约 0.5 秒，随后显式发送零速度保持。姿态俯仰从 -90.68° 增加至 -89.66°，原始相对俯仰从 +90.01° 减少至 +88.99°；运动期间原始 IMU 俯仰角速度采样为 -3.0、-1.9、-2.3、-1.6、-1.8、-1.4°/s。确认 IMU 俯仰角速度也需要反号，不能直接沿用旧反馈符号。硬件错误始终为 0。

### 新版实机闭环核对

已停止旧节点，以 0.3.0 重新启动 `/dev/ttyTHS1`。相对角、姿态角只在当时位置附近变化约 1°，没有执行从中位到 ±90° 的大幅动作。下表是末端采样，单位度，不构成精度标定：

| 新接口 | 俯仰目标 | 对应俯仰反馈 |
| --- | --- | --- |
| `command/relative_angle` | -88.37 | -88.51 |
| `command/relative_angle` | -90.37 | -90.15 |
| `command/attitude` | -89.61 | -89.80 |
| `command/attitude` | -90.80 | -90.62 |

真实角速度 +2°/s、-2°/s 各短时发布约 0.4 秒，转换后的角速度反馈与目标同号，姿态变化方向也相同；停止发布后均验证看门狗停止持续转动。最终恢复测试前相对目标附近并发送零速度保持：相对俯仰 -89.51°，姿态俯仰 -90.05°，硬件错误 0。新版节点保持运行。

本版比例速度仅做协议/伪终端测试，未作实机 FOV/倍率标定。符号映射依据当前立装、固件原始值 36 的设备及用户对抬头/低头的物理观察；吊装、其他固件和全行程尚未验证。

### 历史实机

探测工具收到了 200 个 CRC 正确帧、0 CRC 错误。随后通过运行中的 C++ ROS 节点发送小角度命令，以下是最后一次测试的末端采样，单位度；采样不构成精度标定：

| ROS 目标 | 对应反馈 |
| --- | --- |
| FPV 横滚 +2、俯仰 +2 | 相对角 +1.81、+1.95 |
| FPV 横滚 -2、俯仰 -2 | 相对角 -1.63、-1.81 |
| LOCK 横滚 0、俯仰 +2 | 相机姿态 +0.16、+1.83 |
| LOCK 横滚 0、俯仰 -2 | 相机姿态 +0.19、-1.95 |
| FPV 横滚 0、俯仰 0 | 相对角 +0.02、-0.11 |

默认 `fpv_pitch_command_sign=-1.0` 已应用于上述 FPV 测试。另做过原始符号核对：FPV 线协议俯仰 +2° 得到相对俯仰约 -1.88°，而 LOCK +2° 得到姿态约 +1.84°，因此仅在 FPV ROS 层校正俯仰指令。

角速度测试：LOCK 俯仰 +3°/s，发布约 0.3 秒后停止；0.5 秒看门狗到期后，间隔 0.7 秒的两次姿态俯仰采样均为 -1.29°，确认停止持续转动。最后恢复相对零位附近并发送零速度保持，末次相对横滚 +0.05°、俯仰 -0.02°，硬件错误 0。

测量的两秒反馈频率为约 100.5 Hz（计数窗口有边界误差）；诊断快照有效帧 4,397、CRC 错误 0、丢弃字节 0、拒绝指令 0、硬件错误 0。测试结束已退出驱动，释放串口。
